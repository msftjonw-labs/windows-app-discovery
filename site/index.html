How to read these numbers

Discovery

GraphQL searches examine a bounded, balanced budget of recently updated issues and PRs. Eligible evidence is an issue/PR opening, conversation comment, or submitted PR review in the fixed 30-day UTC window. Closing, pushes, inline review comments, discussions, and releases are not collected in this pilot. The last 20 comments and reviews per item are inspected; omitted connections are counted. Results are ranked by latest observed qualifying activity, not by the latest activity across all of GitHub.

Human activity approximation

GitHub Bot accounts and selected bot-name patterns are excluded. Unresolved actors are not accepted as human evidence. Ordinary User accounts can still operate automation. Issue activity does not necessarily mean code development occurred.

Static analysis

Snapshots are pinned to the default-branch SHA at scan time. Versioned regex/manifest rules infer platform and framework evidence. Windows candidates are scanned by Microsoft Application Inspector with custom pilot rules (bundled rules disabled). No repository code or build scripts are executed. Classification is repository-level, not project-level; monorepos can combine unrelated signals. Comments and strings may produce false positives. Absence of a match is not proof of non-use.

Denominators and exclusions

Platforms, languages, and frameworks use complete scans. Windows application types and components use complete Windows scans with an explicit application indicator. Partial, failed, and no-eligible-source inventories are excluded from headline distributions. A no-eligible-source inventory is not a complete code scan and is shown separately. Zero eligible repositories displays “N/A,” not 0%. Test, sample, generated, vendored, build, and selected dependency directories are excluded. Lock files and known generated artifacts, documentation, datasets, test fixtures, and non-manifest JSON/text assets are outside the declared source scope. Supported source files up to 8 MiB are decoded as UTF-8, BOM-marked UTF-16/UTF-32, or recognizable BOM-less UTF-16, then normalized to UTF-8. Symlinks and submodules are out of scope and never followed. Oversized source archives use bounded GitHub GraphQL blob batches (up to 10,000 files, manifests first), with pinned raw-byte retrieval when GitHub cannot return exact text. Skipped large source files, unsupported encodings, truncated trees, or file/byte retrieval limits make a scan partial. Inspector timeouts, errors, and skipped source also make a scan partial; detected findings are retained, never treated as proof of a complete scan. Forks are retained and labeled, so repositories are not independent applications.

Component adoption = repositories with a detected component ÷ eligible Windows application repositories. This is the equal-weighted average of per-repository detection indicators, not percentage of source lines or runtime calls. Native/Win32 does not prove a GUI; “console / other / unknown” is deliberately unresolved. No accuracy benchmark has yet established precision or recall.
